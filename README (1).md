# AGROVANT — ملفات الموقع

## الملفان
- `index.html` — الموقع كاملا (المتجر + لوحة الإدارة + اللوجو داخله). لا يحتاج تثبيت أو بناء.
- `README.md` — هذا الملف.

## الرفع على Vercel
1. ضع الملفين في مجلد واحد (مثلا `agrovant-site`).
2. في Vercel: Add New > Project، ارفع المجلد أو اربطه بمستودع GitHub.
3. Framework Preset: Other. اترك Build Command فارغا. Output Directory: `.`
4. Deploy. لوحة الإدارة على: `https://موقعك/#admin` (الرقم السري 2011).

## لوحة الإدارة
- الرقم السري 2011 قفل للواجهة فقط. الرقم مكتوب داخل الكود، وأي شخص يفتح مصدر الصفحة يقرؤه.
- لا يوجد دخول حقيقي ولا صلاحيات. لا تضع فيها بيانات حساسة.
- المنتجات المضافة والتعديلات والتذاكر تُحفظ في متصفح كل جهاز (localStorage). لا تنتقل بين الأجهزة.

## ما هو غير مربوط (بصراحة)
| المكوّن | الحالة |
|---|---|
| قاعدة البيانات (Supabase) | غير مربوطة. حساب Supabase ليس فيه أي مشروع حاليا |
| تسجيل دخول العملاء والمدير الحقيقي | غير مفعّل (يحتاج Supabase Auth + RLS) |
| الدفع وإنشاء الطلبات | غير مفعّل |
| واتساب التلقائي (Business API) | غير مفعّل. الموجود فقط فتح محادثة على 010 6363 7022 |
| الشحن | غير مفعّل |

## الخطوة التالية للربط الحقيقي
1. أنشئ مشروعا في Supabase (supabase.com).
2. أعطِ Claude Code البرومبت الكامل ليبني النسخة المرتبطة (Next.js + Supabase + RLS + أدوار).
3. أضف مفاتيح البيئة في Vercel من `.env.example` الذي سيُنشأ. لا ترسل مفتاح service-role في أي محادثة.
